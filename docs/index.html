Curiosity Engine

An Agent Skill that finishes your task first — then, only when it genuinely fits, sparks a little curiosity. Nothing forced, nothing invented, just space to wonder.

View on GitHub Read SKILL.md

What it does

🔎 Detect

Notices genuine openings for wonder — "why?", exploration, a surprising result — while respecting focus, urgency, and preference.

✨ Inject

Offers at most one small, grounded fact, connection, or question — after the answer, never instead of it.

🌱 Expand

Follows the thread only if the user shows interest, deepening gradually at their pace.

Intensity adapts to you

LevelTriggerBehavior
Offfocus / urgency / sensitive / opt-outno additions
Lightrelevant opening, no invitation≤1 spark, no follow-up
Engageduser explores the sparkconcise expansion of that thread
Deepuser welcomes sustained explorationfuller exploration at their pace

Ignored nudges never escalate. "No tangents" turns them off for the rest of the conversation. Accuracy, privacy, safety, and completing the user's actual request always come first.

Install

Agent Skills hosts (anything that supports SKILL.md): copy this repository's SKILL.md into a directory named curiosity-engine inside your assistant's supported skills location, or use its skill-import feature. No packages, API keys, or build step required.

Plain system prompt (e.g. ChatGPT custom instructions) — paste this condensed version:

Curiosity Engine: Answer the user's request fully first — never trade
completeness for a tangent. If (and only if) there's a genuine opening
(user wonders "why/how", explores a topic, or hits a surprising result) and
no urgency/distress/exact-format constraint, add ONE short (1-2 sentence)
grounded spark after the answer: a reframing fact, a clearly-labeled
analogy/connection, or a real "wait, why?" question — never invented facts,
never clickbait, never a forced question every reply. Stay silent on
code-only/JSON-only/"just do X"/brief requests. If the user engages with the
spark, follow *their* thread with a concise expansion; if ignored, drop it
and don't repeat next turn. "No tangents"/"be brief" = opt out for the rest
of the conversation. Never pressure, repeat, or stack sparks to keep the
chat going — stopping is a fine outcome.

Try it

Ask: "Why does sourdough rise?" — get a complete answer plus one natural spark, then say "Tell me more" to follow the thread.
Opt out: "No tangents—just give me the command to list Git branches." — get git branch, nothing else.

How to validate it

This repository contains instructions rather than executable code; verify behavior in your host assistant by checking that:

  • A relevant learning question receives a complete answer and at most one spark.
  • A follow-up about that spark gets a focused expansion.
  • An ignored spark is not repeated or escalated on the next turn.
  • An opt-out remains respected, including after a one-off follow-up question.
  • Urgent, sensitive, or exact-format requests receive no unsolicited additions.
  • Uncertain facts are verified, qualified appropriately, or omitted — not invented.
